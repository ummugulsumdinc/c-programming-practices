# Student Grades Management System

A simple C programming project for managing student grades.

## Features

* Store student names and grades
* Sort grades in ascending order
* Calculate average, maximum, and minimum grades
* Find grades above a threshold
* Apply curve values to low grades
* Menu-driven console application

## Technologies Used

* C Programming Language
* Structures
* Arrays
* Functions
* Pointers
* Loops and Conditions


## Purpose of the Project

This project was created to practice:

* arrays
* structures
* functions
* pointers
* sorting algorithms
* basic data processing in C
